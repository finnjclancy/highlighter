Connect Highlight to ChatGPT

The public Highlight MCP server gives ChatGPT permission to work with the pages, PDFs, and local highlight library in one Chrome profile. Pairing uses a one-time code; your private browser token never goes into ChatGPT.

Public MCP endpointhttps://highlighter-share.finnjclancy.workers.dev/mcp
Set up the connection

  1. Install and open Highlight

    Install the Chrome extension, open an ordinary web page or a PDF in Highlight's reader, and click the Highlight toolbar icon.

  2. Add the public connection

    Install the Highlight plugin when it is available in ChatGPT. Until then, add the endpoint above as a Streamable HTTP MCP server in ChatGPT's Plugins area.

  3. Start OAuth

    Press Connect. ChatGPT opens the Highlight authorization page; leave that page open.

  4. Generate the one-time code

    In the Highlight popup, press ? beside Agent connection, then Pair ChatGPT. The code is copied automatically.

  5. Approve this browser

    Paste the code into the authorization page. It expires after 10 minutes and works only once.

  6. Use Highlight in chat

    Keep Chrome open. Select Highlight from the tools menu—or say @highlight the important things after the public plugin is listed—then ask it to work on the open page or PDF.

Try: “Read the PDF open in Highlight, mark the main claim and every stated limitation, add short notes, and give me a live sharing link.”
What the agent can do
  • Read the active page and browser selection
  • Read an open PDF by page range
  • Create, update, remove, and restore highlights
  • Search highlights and list saved pages
  • Organise folders, tags, notes, and snapshots
  • Summarise or compare marked passages
  • Export Markdown, JSON, CSV, BibTeX, or RIS
  • Create, update, protect, and revoke live links
Troubleshooting

If the code is rejected, generate a new one. If tools say Highlight is disconnected, open the extension and enable Agent connection. The target must be a normal HTTP(S) page or Highlight's PDF Reader; Chrome does not allow extensions on internal pages such as chrome://extensions.

Developer fallback: the help screen can still copy a private MCP URL for compatible development clients. That URL contains a secret and must never be pasted into a chat, screenshot, plugin, or public document.
