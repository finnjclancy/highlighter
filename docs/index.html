Set up in a few minutes

Connect the MCP server to ChatGPT

Highlighter creates and copies the complete private MCP URL for you. Add that connection once, select it in a conversation, and the agent can use all 20 browser tools.

Before you start

No terminal, API key, or server configuration is required. Highlighter handles the browser connection and endpoint.

1
Highlighter

Connect and copy the link

Open the extension and select Connect agent & copy link. You can also press ? and choose Copy private MCP link.

2
ChatGPT settings

Enable developer mode

In ChatGPT, open Settings → Security and login, then turn on Developer mode. Availability can depend on your account or workspace policy.

3
ChatGPT Plugins

Create the connection

Open ChatGPT Plugins, press +, and enter Highlighter as the user-facing name. Add a short description if requested.

4
Connection

Paste the private MCP URL

Choose the public URL / Streamable HTTP connection, paste the complete link, create it, and review the 20 tools ChatGPT discovers.

5
New conversation

Select Highlighter

Start a new conversation, open the tools menu, and add the Highlighter connection so the agent can choose its MCP tools.

6
Browser ready

Open a page and test it

Keep Chrome and Highlighter running, open a normal web page, then give the agent a browser task. Highlights appear directly on that page.

🔒 Your MCP URL is a password. Do not paste it into a post, screenshot, or message. Anyone who has it can use your connected Highlighter while Chrome is open. Select × beside the agent row to disconnect and discard the local token.

Confirm the browser connection

Open an ordinary HTTP(S) article in Chrome and send this prompt:

What page is open in Chrome? List any saved highlights, then suggest one passage worth highlighting. Ask before changing the page.
If it does not connect

Check these three things

Confirm Developer mode is enabled, paste the entire private URL, and keep the paired Chrome extension connected. The connection does not work on internal pages such as chrome://extensions.

Compound interest

Compound interest is interest accumulated from a principal sum and previously accumulated interest. It is the result of reinvesting or retaining interest that would otherwise be paid out.

The effect of compounding depends on the frequency at which interest is compounded and the periodic interest rate which is applied. Therefore, in order to define accurately the amount to be paid under a legal contract with interest, the frequency of compounding (monthly, yearly, etc.) and the interest rate must be specified.

Compound interest is contrasted with simple interest, where previously accumulated interest is not added to the principal amount of the current period.
